# Getting Started - User Guide

Welcome to the Chess Rating Analytics Dashboard! This guide will walk you through your first experience using the application to analyze ECF chess ratings.

## What is the Chess Rating Analytics Dashboard?

The Chess Rating Analytics Dashboard is a web application that provides enhanced analytics for English Chess Federation (ECF) chess ratings. It helps chess players, coaches, and enthusiasts gain deeper insights into rating performance and trends beyond what's available on the standard ECF website.

## Quick Start

### Step 1: Access the Application

Navigate to the Chess Rating Analytics Dashboard in your web browser. The application works on both desktop and mobile devices.

### Step 2: Search for a Player

1. **Find the search box** at the top of the homepage
2. **Start typing a player's name** - the search will show suggestions as you type
3. **Select a player** from the dropdown suggestions
4. **Alternative**: If you know the player's ECF code, you can enter that directly

> **Tip**: The search works with partial names, so you don't need to type the full name exactly.

### Step 3: Explore the Player's Data

Once you've selected a player, you'll see several sections of information:

#### Rating Chart
- **Visual timeline** of the player's rating changes over time
- **Multiple game types**: Standard (classical), Rapid, and Blitz ratings
- **Interactive chart**: Hover over points to see specific dates and ratings

#### Performance Statistics
- **Current ratings** for each game type
- **Recent performance** calculations based on latest games
- **Rating trends** showing whether ratings are improving or declining

#### Game History
- **Recent games** with results and opponent information
- **Event details** showing tournament participation
- **Performance by event** with expandable details

### Step 4: Use Filters and Analysis Tools

#### Time Range Filtering
- **Filter by period**: Choose from 3 months, 6 months, 1 year, 2 years, or all-time
- **Dynamic updates**: Charts and statistics automatically update based on your selection

#### Game Type Selection
- **Switch between**: Standard, Rapid, and Blitz game analysis
- **Compare ratings**: See how performance varies across different time controls

#### Common Opponents
- **Frequent opponents**: See statistics for players you've faced multiple times
- **Win/Loss/Draw ratios**: Understand your performance against specific opponents
- **Head-to-head records**: Click through to see detailed match history

## Understanding Your Data

### Rating Charts

The rating chart shows your rating progression over time:

- **Blue line**: Your official ECF rating for the selected game type
- **Points on the line**: Individual games and rating changes
- **Hover tooltips**: Show exact dates, opponents, and rating changes

### Performance Ratings

Performance ratings are calculated based on your results against opponents:

- **Higher than current rating**: Indicates strong recent performance
- **Lower than current rating**: Suggests recent struggles
- **Sample size matters**: More games provide more reliable performance calculations

### Event Analysis

Events are grouped to show your performance in specific tournaments:

- **Event performance**: Your rating performance in that specific event
- **Expandable details**: Click to see individual games within each event
- **Comparison**: Compare performance across different tournaments

## Tips for Best Results

### Getting Accurate Data
- **ECF registration**: Ensure the player is registered with the ECF
- **Recent activity**: Players with more recent games will have richer data
- **Multiple game types**: Try switching between Standard, Rapid, and Blitz for complete picture

### Using Filters Effectively
- **Recent form**: Use 3-6 month filters to see current form
- **Long-term trends**: Use 1-2 year filters for broader patterns
- **Career overview**: Use "All time" to see complete rating history

### Interpreting Results
- **Rating volatility**: Large swings may indicate inconsistent play or limited games
- **Trend direction**: Look for overall upward or downward trends rather than individual games
- **Opponent strength**: Strong performance against higher-rated players is more significant

## Common Questions

**Q: Why can't I find a player?**
A: The player must be registered with the ECF and have played rated games. Try different spellings or check the ECF website directly.

**Q: Why are some ratings missing?**
A: Players need to have played enough games in a specific category (Standard/Rapid/Blitz) to have an official rating.

**Q: How often is the data updated?**
A: The application fetches the latest data from the ECF API, which is typically updated after each rated event.

**Q: Can I see historical data for players who are no longer active?**
A: Yes, as long as the player has historical ECF data, you can view their complete rating history.
