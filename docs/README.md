## 🏗️ Project Overview

The Chess Rating Analytics Dashboard is a Next.js web application that provides enhanced analytics for English Chess Federation (ECF) ratings. Key features include:

- **Player Search**: Find any ECF-rated player
- **Rating Visualization**: Interactive charts showing rating changes over time
- **Performance Analysis**: Calculate performance ratings and statistics
- **Opponent Analysis**: Statistics for frequently played opponents
- **Event Analysis**: Tournament-based performance insights

## 🛠️ Technology Stack

- **Framework**: Next.js 13 with App Router
- **Frontend**: React with TypeScript
- **Styling**: Tailwind CSS with shadcn/ui components
- **Charts**: Recharts for data visualization
- **Data Fetching**: SWR for caching and state management
